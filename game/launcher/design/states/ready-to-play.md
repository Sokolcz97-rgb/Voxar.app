# Ready To Play reference state

Primary CTA: Hrát

## Preconditions

- supported game build is installed
- file health is acceptable
- no mandatory update blocks launch
- account/session state is sufficient for requested game mode

## Visible content

- signed-in player identity
- current installed version
- channel
- server status
- installation path
- news/world event

If a mandatory update is discovered, this state transitions to Update Available and the primary CTA becomes Aktualizovat.
