# Ready To Install reference state

Primary CTA: Instalovat

## Preconditions

- user may be signed in
- compatible game release is known
- game is not currently installed
- install path has been selected/defaulted
- available disk space has been evaluated

## Status panel

Must show:
- target version
- channel
- install path
- required disk space
- free disk space
- server status

Pressing Install transitions to the Installing state and expands the progress strip.
