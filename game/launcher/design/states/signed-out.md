# Signed Out reference state

Primary CTA: Přihlásit se

## Visible content

- game logo/name
- hero artwork
- game title and short description
- primary sign-in button
- secondary create-account link
- generic account/avatar state
- server status
- installation status if already known
- news panel

## Authentication behavior

`Přihlásit se` opens the StudioVoxario browser authentication handoff.

`Vytvořit účet` opens the existing website registration flow.

No email/password fields are rendered inside the launcher.
