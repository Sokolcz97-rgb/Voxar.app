# Game Launcher / Installer

The game launcher will be designed from scratch and will not reuse the current Voxar.app installer UI as its visual base.

Planned responsibilities:
- first-time installation
- update/repair
- version/channel handling
- sign-in through the existing StudioVoxario web account
- news/server status
- launching the game

## Design rule

Implementation starts only after a reference design is frozen. Layout, typography, spacing, states and assets should be specified explicitly and later checked with screenshot comparison.

## Early distribution

During development the launcher/game will be distributed through dedicated GitHub game releases.

Foundation v0.1 does not publish or attach a `GameSetup.exe`.
